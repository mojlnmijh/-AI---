# 从“写代码”到“说需求”：Vibe Coding 如何让创造力重新定义编程

2025年初，OpenAI联合创始人安德烈·卡帕西在社交平台上提出了一个拗口的新词——Vibe Coding。不到一年，这个词被柯林斯词典收录为2025年度词汇。它的核心主张简单到近乎挑衅：开发者不再需要逐行编写代码，而是用自然语言向AI描述意图，由AI生成、调试并迭代完整的软件项目。

对于没有编程背景的普通人而言，这意味着一个根本性的转变：软件开发的门槛正在从“技能壁垒”滑向“表达门槛”。

## 从“手写工匠”到“战略指挥家”

传统编程的隐喻是搬砖盖房。开发者需要掌握语法的砖块、框架的钢筋、数据库的水泥，一块一块垒起一座能用的建筑。而Vibe Coding的隐喻截然不同：你告诉AI你想要什么样的房子，它先搭出雏形，你再提修改意见，它继续调整，直到你满意。

这一转变在实际案例中已反复得到验证。备考新闻传播学研究生的吴桐雨，因为不会编程，长期困于“把复杂名词解释浓缩成一句话”的复习痛点。今年春天，她开始接触AI编程工具，几轮对话后，一个围绕名词解释设计的网站雏形出现了。经过细节优化，她将“考点便签”网站发布到社交平台，功能全部围绕她自己考研时的需求设计。“我以前完全不懂代码，做出来的时候自己都震惊了。”

一位电力AI公司的工程师，此前十多年在荷兰从事软件开发。今年他在为公司搭建数据平台时，尝试用AI编程工具进行搭建，独自一人只花了10天时间便搭建完成。“以前，开发这样一个平台需要十几个人的团队，大家分工合作大概要花几个月时间，我不到两周就弄出来了。”他感慨，“那一瞬间他真切地感到，事情不太一样了。”

## 工作流：80%的功夫在动嘴之前

成熟的Vibe Coding实践并非“让AI随便生成代码”那么简单。产品设计师Ben Shih在构建一款基于播客内容的角色扮演游戏时，总结出一条关键经验：成功的AI构建，80%取决于开始对话之前的准备。

在技术实现层面，分轮推进是核心节奏。按小目标逐一实现：上传入口、设置项、解析接口、文本选择、接回生成流程。报错不是结束，而是下一轮输入。遇到问题时，直接把错误信息交给AI，让AI帮助解释、定位、修复。一位开发者在实战总结中写道，Vibe Coding的典型陷阱是“总在修复同一个bug”——根源往往在于需求描述不够清晰，或者频繁改变主意导致代码里留下互相矛盾的痕迹。

## 门槛转移而非消失

值得警惕的是，Vibe Coding降低的是“实现门槛”，而非“工程门槛”。安全公司RedAccess发布的一份报告揭示了令人不安的现实：安全人员对公开网络中的Web应用进行扫描，发现了38万个疑似采用Vibe Coding打造的应用，其中至少有5000款应用毫无安全措施，没有设置任何身份验证、访问控制、权限隔离机制，只要外部人员获取正确URL，即可直接访问这些应用及其后台数据。

更严重的是，这5000款应用中约40%已在生产环境中实际使用，其中包含医疗记录、金融数据、企业内部演示文档、客服聊天记录以及个人隐私信息等。部分应用甚至允许搜索引擎索引，意味着普通用户也可能通过搜索直接找到相关页面。

IEEE发表的一项案例研究通过结构化审计发现，AI生成的代码库中存在多类安全漏洞，研究结论明确指出这一范式可能无法可靠地产出安全软件。这意味着普通人在获得创造能力的同时，也需要建立新的判断力。你不必会写代码，但需要知道API密钥不应该出现在浏览器可见的代码中；不必懂数据库设计，但需要测试两个不同账户能否看到彼此的数据。

## 谁在真正受益

从工具生态来看，Vibe Coding正在分化为两条路径：面向专业开发者的Cursor、Claude Code等工具，以及面向普通用户的Replit、Lovable、灵光等平台。数据或许最能说明趋势：全球AI编程工具市场规模在2025年已达295.7亿美元，预计到2030年将攀升至646.8亿美元。Lovable在发布8个月后年收入就达到1亿美元，其中63%的用户是非开发者。

更令人惊讶的是国内00后开发者的崛起。大四学生BaiFu用10天时间通过Vibe Coding做出了开源项目BettaFish，一个能自动抓取舆情并生成分析报告的AI工具，登顶GitHub全球趋势榜第一。随后他收到盛大集团创始人陈天桥的投资意向，24小时内敲定3000万投资，把毕设做成了创业公司。

这些数字背后是一个更深层的命题：当实现能力不再稀缺，稀缺的将是对需求的洞察、对场景的理解、对“什么值得做”的判断力。Vibe Coding没有让工程能力变得不重要，它只是把瓶颈从“能不能做出来”转移到了“该做什么”和“做出来之后呢”。

软件创造力正在大规模走向普通人。但真正的创造者，永远是那些知道为什么要创造的人。
